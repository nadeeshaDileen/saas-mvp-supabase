# Product Overview

This is a **clothing store marketplace SaaS MVP** built with Next.js and Supabase.

## Core Features

- **Multi-tenant architecture**: Store owners can manage their own products, inventory, and orders
- **E-commerce functionality**: Product catalog, shopping cart, checkout with Stripe payments
- **Authentication**: Email/password and OAuth (Google) sign-in
- **Store management dashboard**: Product management, inventory tracking, order fulfillment
- **Customer experience**: Browse products, add to cart, place orders, track order status

## User Roles

- **Store Owners**: Manage products, inventory, orders, and store settings
- **Customers**: Browse products, purchase items, view order history

## Key Workflows

1. Store owners create and manage product listings with variants (size, color)
2. Customers browse the shop, add items to cart, and checkout
3. Payments processed via Stripe
4. Orders tracked through fulfillment lifecycle
5. Store owners can export order data and manage inventory
